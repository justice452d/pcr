# PCR 综合研究台（本地版）

双击 `START_PCR_DASHBOARD.bat` 启动。浏览器会打开 `http://127.0.0.1:8090`（若被占用则顺延选择空闲端口）；程序窗口保持运行时，网页才会持续自动更新。同一局域网设备可使用页面右上角显示的地址访问。

## 已整合模块

- 期权 PCR：沪深300、沪金、沪银、沪铜、原油；均可选择“裸 PCR（全部合约）”或“近月 PCR”。两种口径分别计算 BB(20,2)。
- 恒指 / 恒生科技：保留共享缓存中的近五年期权 OI，右图为对应现货指数收盘价，不再显示历史百分位。
- 股债利差：上证指数、中证全指、CHINA50（公开可复算的上证50估值口径）集中切换。
- A 股中期估值温度：只保留中证全指 PE-TTM 月频主体。
- 红利低波估值：中证红利低波动指数 H30269 的股息率、股债利差与 PB 三因子温度；支持 5Y/10Y/ALL、可调权重、历史温度与价格叠加、养老金定投参考和手动数据备用。

## 自动更新

- 内地期权：工作日 15:30 后每 10 分钟检查公开日行情；缓存仍统一写入 `H:\PCR\cache`。
- 恒指 / 恒科：沿用港交所日报与结算文件的增量补齐逻辑，并刷新指数价格。
- 指数与中债收益率：工作日 18:00 后检查；失败时继续使用最后一次已核实缓存。
- 月度估值：每月月初由最新日频 PE-TTM 重建月末序列，也可在网页中手动点“更新月度数据”。
- 红利低波估值：工作日收盘后随统一市场调度每日检查一次。原始与计算结果缓存在 `H:\PCR\cache\valuation\dividend_low_vol_history.json`；自动源失败时继续显示缓存并明确提示。

## 口径说明

近月是当日仍有有效 Put/Call 持仓的最早到期月份。裸 PCR 是全部有效到期月的 Put OI 合计除以 Call OI 合计。CHINA50 页使用上证50（000016）作为可持续公开更新的在岸 50 龙头估值代理，不冒充富时中国 A50 官方估值序列。

PCR 图的鼠标提示同时显示所选口径的 Put OI、Call OI、相对上一交易日的持仓变化及变化率。近月合约发生换月时不跨月计算变化，提示中会明确标记“换月，不计算”。

红利低波模块采用 H30269。中证官方日频估值文件提供股息率但不提供 PB；PB 暂取官方月度事实表快照，页面显示快照日期，历史逐步积累或由 `H:\PCR\cache\valuation\valuation_manual.json` / `.csv` 补齐。计算公式与数据链路详见 `sources\dividend_low_vol\README.md`。
