大宗期权 PCR 雷达

Windows: 双击 START_WINDOWS.bat。需要 Python 3 与互联网；启动器安装 pdfplumber。浏览器自动打开本次整合版地址（默认 http://127.0.0.1:8070/hk）。
沪金原版在 http://127.0.0.1:8070/shfe；沪银在 /shfe/silver、沪铜在 /shfe/copper、上期能源原油在 /shfe/oil，同一网页顶部导航可进入。沪银、沪铜、SC 原油使用与沪金相同的上期所逐日原始行情入口，按看跌/看涨合约汇总持仓，与官方「小计」逐日对账。data/shfe_history.json 包含已经回填的历史，网页直接读取，不必首次打开时等待逐日下载；文件中保留来源、日期、合约数、PCR 及相应代表期货合约的收盘价。原油（SC）与 WTI 为不同合约，不合并历史。
网页价格选取当日期货持仓量最大的合约，随时间换月，价格曲线在换月处可能跳变；回测信号请使用交易当时已经公布的 PCR，不能把当日结算后公布的持仓量视为当日收盘前可得。每次回填可在本机运行 python backfill_shfe.py --days 260，失败日会报告且不会伪造记录。网页无此文件时仍会尝试现场下载最近的历史。

CME 9 品种：黄金、白银、铜、WTI 原油、天然气、玉米、大豆、小麦、豆油。持仓量 PCR = Put OI / Call OI。CME 取官方 Daily Bulletin 的标准月度期权，不含周度/微型；上期所黄金单独保留原有统计口径。
CME 公告通常于美国下一个工作日公布；程序启动立即检查，正常时每 6 小时、出错时每小时重试，即使浏览器已关闭也继续运行。网页打开时也检查、之后每小时检查。若当地网络无法访问 cmegroup.com，页面会显示错误，已抓取历史仍可查看。最新 PDF 不是公开的长跨度历史 API，数据从首次运行成功后逐日累积；20 个交易日后才显示 BB(20,2)，不回填虚构历史。
CME 的 PDF 版式可能调整；遇到解析不足时显示异常，不会生成猜测值。程序窗口保持运行才能自动刷新。data 目录保存累积历史，转移电脑时一并复制。
独立的 commodity_pcr_history.csv 保存 CME 初始及云端定时新增记录；将更新后的 CSV 下载并拖到 IMPORT_HISTORY_WINDOWS.bat 可补入本地 CME 网页。电脑关闭时本地程序无法采集，云端记录不会自动出现在本地网页。

历史数据导入：获得经过授权的日频历史文件后，整理成 UTF-8 CSV，表头 date,product,put_oi,call_oi（可选 futures_close）；date 为 YYYY-MM-DD 美盘交易日，product 为 gold/silver/copper/wti/gas/corn/soybean/wheat/soyoil。将文件拖到 IMPORT_HISTORY_WINDOWS.bat，程序会校验并保存；同日期不同数据会拒绝覆盖。切勿把成交量 PCR、周度/微型期权与标准月度期权持仓量混入同一条序列。

沪深300股指期权 IO PCR（新增）
- 地址：http://127.0.0.1:8070/cffex/io
- 数据源：中金所官方日行情。Python 服务端优先抓单日 CSV；单日文件不可用时自动读取官方月度历史 ZIP，网页不直接跨域访问中金所，因此不受浏览器 CORS 限制。
- 口径：全部 IO 看跌期权持仓量 / 全部 IO 看涨期权持仓量；20日均值 ± 2 倍总体标准差。
- IF 价格：每天取 IF 持仓量最大的期货合约收盘价，仅用于价格对照。
- 默认读取 260 个有效交易日；第一次会下载历史，之后使用 cache/cffex 缓存。也可选择 35/60/120/520 日。
- 工作日 15:30 后每 10 分钟检查最新日行情；发现新交易日后当天停止检查，与沪金页面的刷新节奏一致。
- 页面内置 2026-03-27、04-17、08-18 三个截图锚点，并同时比较“当日PCR”和“前一交易日PCR”，用于判断博主图中“开盘值”是否是前一日结算持仓PCR。

V3 修复：BB(20,2) 先在完整历史（含19个预热交易日）上计算，再按 35/60/120/260/520 日裁剪显示；同一日期的 MA20/上下轨不再随查看区间变化。

[v4 修复]
- CFFEX IO 的 BB(20,2) 改为“服务端统一完整序列先计算，再按 35/60/120/260/520 日切片”。同一日期的 MA20/上下轨不会因显示范围改变。
- 历史月度 ZIP 优先构造规范交易日序列，避免不同范围分别并发抓取时，偶发网络失败导致某些交易日缺失、滚动窗口错位。
- 当前月份 ZIP 不再永久缓存；每次需要时会刷新，避免昨日的当月 ZIP 让今日数据永久缺失。
- latest 会强制刷新，并把刚成功读取的最新交易日注入历史规范序列。
- PCR/IF 图新增真正的十字星；鼠标坐标通过 SVG CTM 反变换定位，不再因响应式缩放导致日期偏移。

=== v9 公共缓存 ===

3) 旧版本 data 下其它 CME *.json 可选；v9 首次启动也会尝试自动迁移。
