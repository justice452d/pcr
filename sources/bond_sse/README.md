# 上证指数股债利差 · 重建版

打开 `index.html` 查看可离线交互的走势图。红线是上证指数（000001），蓝线是以**同一个上证指数的 PE-TTM**计算的股债利差，三条平滑线分别是利差的滚动均值、上轨、下轨。数据截至 2026-09-24。这个版本用于回应「红线应是上证指数」；保留另一个中证全指版本供对照，两个版本各自用本指数的 PE 计算蓝线。

## 算法

- 股票盈利收益率（%） = `100 / 上证指数 PE-TTM`。
- 股债利差（百分点） = `股票盈利收益率 - 中债国债 10 年期到期收益率`。
- 默认轨道 = 过去 756 个**共同有效观测日**（含当日）的利差均值 ±2 倍总体标准差；不足 500 个观测日不画轨道。页面可选 1260 日及 ±1σ。数据有历史缺口，756 行不一定等于恰好 3 个自然年。

2026-09-24：上证指数 3888.37 点、PE 14.57 倍、国债收益率 1.6738%，所以盈利收益率 6.8634%，利差 5.1896 个百分点；均值 5.3936%，下轨 4.0706%，上轨 6.7165%，当前位置 -0.31σ，**没有跌破下轨**。同日中证全指版的 PE 为 17.60 倍、利差 4.0080 个百分点，当前位置约 -0.32σ。两条蓝线数值不同，不能只替换红线而沿用原来的蓝线。

2025 年的首次下穿 -2σ：上证版为 8 月 25 日；原中证全指版为 9 月 11 日。这说明换指数可能改变信号日期。下轨属于自行设定的统计区间，不是原视频的精确算法。蓝线低于下轨表示股票过去盈利相对国债收益率偏低，不能据此证明债券资金已经流入股市。

## 原始数据与复算

| 文件 | 说明 |
| --- | --- |
| `sse_composite_daily.csv` | 中证指数官网历史行情接口 `https://www.csindex.com.cn/csindex-home/perf/index-perf?indexCode=000001` 中的收盘点位与 `peg` 字段；字段的 PE-TTM 含义参照公开第三方接口映射，2026-09-24 为止；删除交易量为零的回填行。 |
| `bond_10y_daily.csv` | 2025-05-23 及以前为公开整理的中债收益率数据 `https://github.com/guido233/YieldScope/blob/main/full_bond_yield_2000_2025.csv`；此后为中债国债曲线历史查询 `https://yield.chinabond.com.cn/cbweb-cbrc-web/cbrc/showHistory?locale=cn_ZH&mark=1`，各行含 `source`。 |
| `daily_data.csv` | `build.py` 按日期精确匹配并计算，共 3625 个共同观测日，2011-08-02 至 2026-09-24；2012 年初历史 PE 有缺口，不插值。 |

在本目录运行 `python build.py` 可重算 CSV、JSON 和离线网页。文件内数据不会自动更新；要刷新需先更新两份原始 CSV。历史 PE 口径及指数成份变更、亏损公司处理可能影响精确比较。本图是简化盈利收益率差，不是可直接观测的预期股权风险溢价，也不是资金流向指标。
