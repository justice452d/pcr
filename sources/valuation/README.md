# A股中期估值温度 · 研究版

打开 `index.html` 即可查看；不需要安装软件或联网。页面已内置中证全指从 2011-08-02（指数发布日期）到 2026-09-24 的收盘点位和滚动市盈率数据，提供按月的 PE 分位和关键月份后续价格表现。

| 月份 | 中证全指PE | 当时可得滚动分位 | 后6个月点位变动 | 后12个月点位变动 |
| --- | ---: | ---: | ---: | ---: |

| 2018-12 | 12.94 | 16.67% | +23.65% | +31.11% |

| 2024-02 | 13.56 | 10.42% | -9.33% | +14.02% |
| 2026-09 | 17.60 | 61.25% | — | — |

数据按每月最后一个有数据的日期采样；2026-09 的实际最新数据日期为 2026-09-24。源站缺少 2012 年 1—2 月可用 PE，故月度序列在此有缺口。分位使用当月和过去最多119个有效月度观测，起始不足36个月时不显示；2015年实际积累不足48个有效观测，不能误称完整十年回溯。后续回报是点位涨跌，不含股息。按月观察值互相重叠，不可以把分组中位收益当作独立样本的显著性检验。

## 尚未完成的综合回测

没有取得覆盖2011年至今、口径稳定、可逐月核验的等权PB、全A总市值、GDP实际发布日期和10年国债收益率五项原始序列。因此没有生成“综合温度”历史曲线或当前分数，也没有宣称三个因子在上述拐点都有效。页面提供导入完整数据后的本地计算。数据必须由使用者核实来源。

所需 CSV 表头：

```csv
date,market_cap_a_cny,gdp_ttm_cny,gdp_release_date,pb_equal,pe_weighted,yield10_pct
```

每行是月末数据。市值和GDP是人民币元，10年收益率以百分数填，例如 `1.8`。GDP列必须是观测日已公开的最近四季度名义GDP，不能把后来修订的数据倒填到历史上；页面检查发布日不晚于该月观察日，但无法验证公布数据的真实性。若同一月份有多行，保留最后一行；建议每月只有一行且日期升序。至少36个连续月才开始计算分位；正式十年窗口需要120个月。

公式：市值GDP比=全A总市值/滚动名义GDP；ERP（百分点）=100/全A加权PE−10年国债收益率（百分点）；总分=0.25×市值GDP比分位+0.35×等权PB分位+0.40×(100−ERP分位)。这是一组预设权重，**未经三因子历史数据实证检验**。

## 可复算文件

- `csi_all_share_daily.csv`：中证全指历史数据，含日期、点位、PE、成交量。
- `csi_monthly_study.csv`：逐月分位与后6/12个月点位变化。
- `fetch_index.py`：从中证指数官网获取历史数据，联网时运行。
- `analyze.py`：从日频数据计算月频回测，标准库 Python 运行。
- `full_factor_template.csv`：空表头，仅作导入格式模板。

源头：中证指数官方历史行情接口：<https://www.csindex.com.cn/csindex-home/perf/index-perf?indexCode=000985>。该接口的 `peg` 字段在其公开第三方接口说明中映射为“滚动市盈率”；将该字段视为 PE-TTM，不将它当成 PEG 增长调整估值。理杏仁指数估值字段及权重定义：<https://www.lixinger.com/api/open-api/html-doc/cn/index/fundamental>。中债10年国债历史数据入口：<https://yield.chinabond.com.cn/cbweb-cbrc-web/cbrc/showHistory?locale=cn_ZH&mark=1>。

注意：中证全指成份随时间调整，2011年起的PE序列与严格的“全部上市A股”有样本差异；未来如果ERP使用另一个提供商的全A PE，要先核对样本、亏损公司处理与估值算法。市值/GDP还受新股上市及上市范围扩展影响，历史绝对阈值不可机械沿用。
