# 中证全指股债利差 · 重建版

打开 `index.html` 查看已内置历史数据的交互曲线，无需安装或联网。蓝线是简化股债利差，红线是中证全指，另有利差的移动均值、上轨、下轨。数据截至 2026-09-24。页面支持近3年/6年/全历史及3年/5年窗口、±1/±2标准差的切换。这是**按相似形态重建，不是原作者指标的精确复刻**。

## 公式及方向

- 股票盈利收益率（%） = `100 / 中证全指滚动PE`。
- 蓝线股债利差（百分点） = `股票盈利收益率 - 中债国债10年期到期收益率`。
- 中轨 = 利差过去最多756个**有效共同观测日**（含当日）的算术平均。
- 上/下轨 = 中轨 ±2×同期总体标准差。样本不足500个观测日时不画轨道。页面可切换为1260日窗口及±1σ。756个共同观测约为三年，若源头缺月，实际跨度会更长。

例如 2026-09-24，中证全指PE=17.60，盈利收益率约5.6818%，中债10Y=1.6738%，利差=4.0080个百分点。756日均值4.2055%，下轨2.9810%，上轨5.4300%；目前位于轨道内，距均值-0.32σ。

蓝线低于下轨，意味着股票盈利收益率相对国债异常低，或股票相对国债偏贵。它不能证明债券资金已经流入股市，也不保证之后大盘下跌。图上股票下跌时蓝线往往机械地走高，因为股价下跌使PE降低、盈利收益率上升；两条线的反向关系不能本身算作预测能力。国债收益率下行也可独立推高蓝线，盈利周期也会改变PE。

## 数据来源与限制

| 文件 | 来源 | 范围 |
| --- | --- | --- |
| `csi_all_share_daily.csv` | 中证指数000985历史行情接口 `https://www.csindex.com.cn/csindex-home/perf/index-perf`；字段 `peg` 按第三方公开接口说明映射为“滚动市盈率” | 2011-08-02至2026-09-24，有历史缺口；剔除接口对1月1日的回填行 |
| `bond_10y_daily.csv` | 至2025-05-23来自公开整理数据 `https://github.com/guido233/YieldScope/blob/main/full_bond_yield_2000_2025.csv`，该项目注明原始来源为中债；2025-05-26至2026-09-24直接取自中债国债曲线历史查询 `https://yield.chinabond.com.cn/cbweb-cbrc-web/cbrc/showHistory?locale=cn_ZH&mark=1` | 2011-08至2026-09-24；每条记录标明来源 |
| `daily_data.csv` | `build.py`按日期精确匹配以上两组数据并计算 | 3627个共同观测日 |

2012年1—2月，中证指数历史接口缺少可用滚动PE，直接留空；不插值。两个平台对指数PE的亏损处理、样本成份及历史修订口径可能不同。图只重建**简化股债利差**，不是能观察到的真实未来股权风险溢价。截图未提供原作者的指标代码、股票指数、PE来源、10年国债曲线、标准差窗口与倍数，无法宣称逐点一致。

2025年9月第一次下穿本版-2σ发生在9月11日；之后还曾多次反复穿越，不应把10次穿越当作10个独立信号。2026年9月24日已经回归区间，位置-0.32σ。截图“跌破下轨就有债券资金流入股市”的文字是一种解释，并非从本数据可证明的资金流动。

## 复算

压缩包解压后，在同一目录运行 `python build.py`（只用Python标准库），即可由两份原始CSV重算 `daily_data.csv`、`data.json` 与 `index.html`。更新日频原始CSV后再次运行即可刷新网页；当前交付文件**不会自动在线更新**。打开 `index.html` 可查看内置数据。
